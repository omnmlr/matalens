| Reference | Evidence and decision |
| --- | --- |
| VotersDesk | The public ballot index groups states geographically and promises an alphabetical candidate list. Its Vote Ready guide walks through voter status, polling location, travel and what to bring. Its editorial page describes uniform candidate fields and source attribution. MataLens uses short, sourced steps, one locally browsable race, private checklists and objective exercises. Its visual assets, branding, structure and implementation are independently created. [Ballot index](https://votersdesk.ng/ballot) · [Vote Ready](https://votersdesk.ng/vote-ready) · [Editorial approach](https://votersdesk.ng/about) |
| FixMyStreet | The UK homepage offers postcode/street, geolocation and photo-first entry. Its source separates location, context, preview and report confirmation, including a map-skip path and unsubmitted-state copy. The platform supports public reports and authority routing. MataLens uses optional descriptive location, explicit photo safety, private receipt access and a platform-only status. Source review used commit `3f38dcc104a7cc94303e62b1d77fd9e07ff598fa`. Most of the repository is AGPL-3.0-or-later. No code or assets were imported. [Public interface](https://www.fixmystreet.com/) · [Workflow](https://fixmystreet.org/how-it-works/) · [Report template](https://github.com/mysociety/fixmystreet/blob/3f38dcc104a7cc94303e62b1d77fd9e07ff598fa/templates/web/base/report/new/form_report.html) · [Licence](https://github.com/mysociety/fixmystreet/blob/3f38dcc104a7cc94303e62b1d77fd9e07ff598fa/LICENSE.txt) |
