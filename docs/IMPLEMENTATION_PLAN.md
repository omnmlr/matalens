# First release plan

1. Research public civic tools and primary election sources. Document licensing decisions and publish a small, dated case study alongside current official guidance.
2. Build a responsive React + TypeScript app with Vite, original visual assets, light and dark themes, accessible navigation, private local preparation and offline access to the app after the first load.
3. Build a Node + SQLite intake with transactional evidence, private receipt recovery, withdrawal, moderation, retention and validation. Use one process and a private persistent volume for the pilot. Public intake stays off until configured.
4. Verify the entire guest flow in Chromium at phone and desktop widths, test state and failure paths, capture screenshots, then commit and open a draft PR if authorized tooling permits.
