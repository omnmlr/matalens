# Election data and provenance

MataLens publishes **248 candidacies across 22 contests and 21 parties**, with 70 named running mates attached to their tickets. The catalogue covers the two national presidential rosters and selected state, Senate, federal constituency and state constituency contests in Edo, Lagos and Oyo. A state filter searches that state’s local records. National presidential records have their own filter.

## Import and corrections

`data/election-source-records.json` contains reviewed factual transcriptions with source row references, explicit coverage counts and publication dates where available. The importer validates each complete contest, its office and geography, row continuity, one candidacy per party per contest, ticket pairs, route IDs, 2023 listing/declaration identity matches and vote totals. Run `npm run data:import` after a source edit. The build runs `npm run data:check` against the normalized snapshot so it cannot drift.

The snapshot separates identities from election-specific candidacies, parties, offices and geography. The same identity can have different parties in different elections. Shared identity links use explicit aliases or matching names within the national ticket data. Constituency and district slugs carry the office so similarly named areas remain separate. Additional profile records cite their own source and date or review date. Qualifications represent the INEC listing. Omitted records have no inferred qualification, policy position or political affiliation.

Record a source revision by updating its review date and preserving the superseded evidence and reason in the Git history. Keep earlier declarations and nomination versions distinguishable. Check the press publications for amended candidate names, especially court-ordered changes, before any public demonstration. The in-app correction tool prepares a copyable note. Delivery requires a verified destination.

## External datasets and media

VotersDesk advertises CC BY 4.0 for its published data exports and requests attribution to “VotersDesk (votersdesk.com.ng)” with a link back. Its landing page displayed all three advertised column lists. The three download attempts failed from this runtime because the proxy returned HTTP 403 during connection. The web connector could read the landing page but could not read the CSVs. No VotersDesk records were imported. [VotersDesk Open Data](https://votersdesk.ng/open-data) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

| Advertised export | Schema shown on landing page |
| --- | --- |
| candidates.csv | year, election, state, constituency, race, candidate, party, party_name, stage, running_mate, profile_url |
| parties.csv | acronym, name, profile_url |
| results.csv | race, level, area, candidate, party, votes, label, source, source_url, reported_at, published_by |

MataLens uses INEC facts and original symbol clues. The symbol exercise points to the relevant INEC report or INEC-hosted party constitution. Official logo artwork still needs its own reuse review. Profile photographs use a neutral fallback. Three possible Wikimedia photographs had explicit licences on their file pages, but the binary fetches returned HTTP 403 in this environment. The relevant profiles link to those credited file pages.
