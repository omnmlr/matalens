## 1. Executive Summary & Pitch Architecture

$$\text{Opening Hook } (20\text{s}) \longrightarrow \text{The Problem } (25\text{s}) \longrightarrow \text{The Solution \& Live Walkthrough } (105\text{s}) \longrightarrow \text{Closing Punch } (30\text{s})$$

### The 10-Second Elevator Pitch:
> *"MataLens is Nigeria's first personal, nonpartisan political-learning companion. We turn overwhelming political news into daily, sourced clarity—connecting today's headlines directly to signed campaign manifestos, multi-source perspectives, and 60-second constitutional rehearsals, with zero mandatory sign-in."*

## 3. Presenter Delivery Guidelines & Checklist

1. **Pacing:** Speak at a steady 130–140 words per minute. Do not rush; let the visual transitions breathe.
2. **Device Setup:** Run the demo on a laptop connected to a high-contrast external monitor at $1920 \times 1080$ resolution, with browser zoom set to 110% for optimal jury legibility.
3. **Data Saver Mode Mention:** If bandwidth lags on the presentation Wi-Fi, toggle the **[Data Saver]** button in the header and say: *"Notice how our Data Saver mode suppresses heavy assets and loads under 120KB—engineered specifically for real Nigerian cellular networks."*
